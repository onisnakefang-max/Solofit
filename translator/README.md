# xbox_subs — русские субтитры для английских игр на Xbox Series X

Приложение **на Xbox поставить нельзя**: консоль не даёт стороннему приложению ни звук, ни картинку чужой игры,
ни рисовать поверх неё. Поэтому схема такая:

```
Xbox Series X ──HDMI──► HDMI-сплиттер / карта захвата ──USB──► ПК (xbox_subs) ──► экран с русскими субтитрами
                              └──HDMI──► телевизор (без задержки, как обычно)
```

Приложение читает кадры с карты захвата, находит английские субтитры (OCR), переводит и рисует русский текст.

## Что нужно
- Карта захвата или сплиттер с USB-выходом (любая UVC-карта, в системе должна видеться как веб-камера). HDCP на субтитрах игр обычно не мешает; в настройках Xbox выключите HDR/Dolby Vision для захвата.
- ПК с Python 3.10+.

## Запуск
```
pip install -r requirements.txt
python -m xbox_subs --source 0                 # окно с видео и русскими субтитрами
python -m xbox_subs --source 0 --display overlay   # прозрачный оверлей поверх всех окон (Windows)
python -m xbox_subs --source кадр.png --display console   # проверка на картинке/видеофайле
```
Параметры: `--source` (0,1,… номер карты / `screen` / файл), `--region x,y,w,h` (доли кадра, где игра рисует субтитры,
по умолчанию нижняя четверть), `--engine argos|google`, `--ocr-fps`.

Перевод: `argos` — офлайн, пакет en→ru (~100 МБ) качается при первом запуске; `google` — онлайн, качество выше.
В игре включите английские субтитры, крупный размер и контрастный фон — OCR читает их заметно лучше.

## Как устроено
`capture` (кадры) → `Region` (область субтитров) → `RapidOcr` (текст, не чаще `--ocr-fps`, пропускается на неподвижной картинке) →
`Stabilizer` (реплика принимается после 2 одинаковых чтений, мелкие ошибки OCR не считаются новой репликой, гаснет после пустых чтений) →
`CachedTranslator` → `render`/`overlay`.

## Тесты
```
python -m pytest
```

## Ограничения
- Переводится только текст на экране (субтитры, меню). Перевода речи нет — это отдельный этап (Whisper по аудио с карты захвата).
- Задержка 0,3–1 с: OCR + перевод. Видео на ТВ идёт без задержки, субтитры чуть запаздывают.
- Оверлей и камера проверены только в юнит-тестах и на синтетическом кадре; на реальной карте захвата и Windows ещё не запускались.
