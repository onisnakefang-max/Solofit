# Arise: Система — фитнес-RPG в духе Solo Leveling

Android-приложение (Kotlin + Jetpack Compose), которое превращает тренировки в игру: ежедневный квест,
ранги, статы, штрафная зона, еженедельные подземелья с боссами и армия теней.

## Как это работает

| Механика | Что делает |
|---|---|
| **Ежедневный квест** | Отжимания, пресс, приседания, бег, планка. Цели растут с уровнем до «100/100/100/10 км». Опыт идёт за каждый записанный подход. |
| **Штрафная зона** | Пропустил день: серия обнуляется, теряется часть опыта, появляется штраф в берпи. Пока штраф не закрыт, опыт делится пополам. |
| **Ранги и статы** | Ранг E → S по уровню. Статы (сила, ловкость, выносливость, интеллект) растут за упражнения. За уровень даётся 3 свободных очка. |
| **Подземелья** | Каждую неделю новый босс. Весь объём тренировок бьёт его. Победа даёт опыт и шанс извлечь тень. |
| **Армия теней** | 9 теней, каждая даёт постоянный бонус к опыту. Шанс извлечения растёт с интеллектом и после неудач. |
| **День отдыха** | Жетон спасает серию от штрафа. Жетон даётся за каждую неделю серии, максимум 2. |
| **Таймеры и напоминания** | Таймер отдыха между подходами, секундомер планки, уведомление после выбранного часа. |

Подтверждение тренировки — самоотчёт (честность на тебе) + таймеры.

## Сборка

**Android Studio:** открыть папку `SoloFit`, дождаться синхронизации Gradle, нажать Run. Нужны Android Studio Ladybug+ и JDK 17.

**Командная строка:**
```
./gradlew testDebugUnitTest   # тесты игровой логики
./gradlew assembleDebug       # APK: app/build/outputs/apk/debug/app-debug.apk
```

**GitHub Actions:** запушь проект в репозиторий. Workflow `.github/workflows/android.yml` соберёт APK
и приложит его как артефакт. Скачай и поставь на телефон.

## Структура

- `game/` — чистая игровая логика без Android (`GameEngine`), покрыта тестами в `src/test`.
- `data/` — сохранение в SharedPreferences (JSON).
- `ui/` — Compose-экраны в стиле «окон Системы».
- `notify/` — WorkManager-напоминания.

## Куда развивать

Сезонные «Красные врата» с особыми заданиями, больше упражнений (подтягивания, прыжки), Health Connect
для автоматического подсчёта шагов и бега, экспорт и резервное копирование прогресса, виджет с квестом на домашнем экране.
